# Minhas Contas - PWA
Como instalar / usar:
1. Copie TODA a pasta app-contas-pwa para seu hosting (Netlify, Vercel, GitHub Pages) ou abra com Live Server no VS Code.
2. Abra no celular (Chrome Android / Safari iPhone) > Compartilhar > Adicionar à Tela Inicial.
3. Pronto: abre em tela cheia, funciona offline, ícone próprio.
Arquivos:
- index.html = app completo
- manifest.json = nome, cor, ícone do app
- sw.js = funciona offline
- icon-*.png = ícones
